# TOTA STORE — Starter MVP

واجهة أولية تجريبية لمتجر متعدد الأقسام بهوية بنفسجي/فوشيا/أسود.

## التشغيل محليًا
1. ثبّت Node.js (إصدار LTS).
2. فك ضغط المشروع وافتح مجلده في Terminal.
3. نفّذ:
   ```bash
   npm install
   npm run dev
   ```
4. افتح `http://localhost:3000`.

## الموجود حاليًا
- واجهة عربية RTL ومتجاوبة.
- هوية بصرية شبابية بنفسجي وفوشيا.
- أقسام تجريبية.
- بحث بسيط بالاسم.
- فلترة حسب القسم.
- إضافة للسلة وتعديل الكميات وعرض الإجمالي التجريبي.

## غير موجود بعد
- قاعدة بيانات أو تسجيل دخول.
- لوحة إدارة فعلية.
- إتمام الطلب أو حفظ الطلبات.
- دفع إلكتروني أو تكامل شحن.
- تطبيق Android/iOS.

## الخطوة التالية
تثبيت بيئة التشغيل ثم ربط Supabase، وبعدها إنشاء إدارة المنتجات والطلبات. المنتجات والأسعار الحالية أمثلة شكلية وليست عروضًا حقيقية.
